### 1. 實驗目標
- 驗證 L239D 能否正常控制直流馬達。
- 掌握L239D之使用方式，以及直流馬達之觀念。
- 學習透過 Arduino IDE 類比輸入腳位獲取資料，並且利用其控制馬達。

### 2. 設備與元件
- Arduino Uno 開發板 x 1
- USB Type-B 傳輸線 x 1
- 個人電腦（已安裝 Arduino IDE）x 1
- 可變電阻 x 1
- L239D IC x 1
- DC Motor x 1

### 3. 操作說明與成果
1. **連接電路**：將 Arduino Uno 上的 5V 、 GND接到L239D IC的電源腳位，Uno板的digital pin10、pin11分別接到L239D的IN1、IN2，可變電阻第1、3腳分別接上5V、GND，滑動接腳接到A0，再將Pin6接到L239D的ENA，利用PWM做控制。
2. **燒錄程式** 將Arduino Uno連接上電腦，並將 `Task2-1.ino` 燒錄至 Arduino Uno 上
3. **實驗成果**：旋轉可變電阻，觀察馬達轉速與方向，可以發現當可變電阻轉到一半附近時馬達停下，從中間向左轉，馬達會隨著可變電阻轉的幅度而提升速度，從中間向右轉，馬達則是會往另一個放向旋轉，速度一樣會隨可變電阻幅度變動。
4. **操作影片**：請參閱同目錄下 `video/Task2-1.mp4` 之實際操作畫面。
