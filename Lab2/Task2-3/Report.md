### 1. 實驗目標
- 驗證中斷與輪詢之差別。
- 掌握Interrupt之使用方式，以及Polling之觀念。
- 學習透過連接相同電路，但不同控制之方法，觀察結果並進行比較。

### 2. 設備與元件
- Arduino Uno 開發板 x 1
- USB Type-B 傳輸線 x 1
- 個人電腦（已安裝 Arduino IDE）x 1
- 按鈕 x 2
- LED x 2
- 電阻 x 2

### 3. 操作說明與成果
1. **連接電路**：將兩個按鈕兩端分別接到GND、digital Pin上(Pin2 、Pin3)，兩顆LED經過電阻分別接到digital Pin(Pin4、Pin5)，另一端接到GND。
2. **燒錄程式** 將Arduino Uno連接上電腦，並將 `Task2-3.ino` 燒錄至 Arduino Uno 上
3. **實驗成果**：按下按鈕可以看到使用中斷的按鈕，LED不管按鈕按多快都會變化(可能因bounce沒有變化)，但輪詢的LED每次都必須等2秒才能改變狀態。
4. **操作影片**：請參閱同目錄下 `video/Task2-3.mp4` 之實際操作畫面。
